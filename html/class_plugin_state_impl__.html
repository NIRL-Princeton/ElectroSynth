Detailed Description

template<typename ParameterState, typename NonParameterState = chowdsp::NonParamState, typename Serializer = chowdsp::XMLSerializer>
class PluginStateImpl_< ParameterState, NonParameterState, Serializer >

Template type to hold a plugin's state.

Template Parameters
ParameterStateStruct containing all of the plugin's parameters as chowdsp::OptionalPointer's.
NonParameterStateStruct containing all of the plugin's non-parameter state as StateValue objects.
SerializerA type that implements chowdsp::BaseSerializer (JSONSerializer by default)
